# homel-dev

Open infrastructure for local AI systems: Kubernetes, GPU inference,
observability, automation, and deterministic memory.

## Engineering standards

Organization-wide engineering policy is maintained in this repository:

- [Engineering Style Guide](https://github.com/homel-dev/.github/blob/main/docs/01_engineering_style_guide.md)
- [Documentation Style Guide](https://github.com/homel-dev/.github/blob/main/docs/02_documentation_style_guide.md)
- [Repository Conventions](https://github.com/homel-dev/.github/blob/main/docs/03_repository_conventions.md)
- [CI Standard](https://github.com/homel-dev/.github/blob/main/docs/04_ci_standard.md)

Repository-local rules may extend these standards. Intentional deviations must
be explicit and documented.
