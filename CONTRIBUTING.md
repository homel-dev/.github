# Contributing

Repositories in the `homel-dev` organization follow shared engineering and
documentation standards maintained in this `.github` repository.

Canonical policy:

- [Engineering Style Guide](docs/01_engineering_style_guide.md)
- [Documentation Style Guide](docs/02_documentation_style_guide.md)
- [Repository Conventions](docs/03_repository_conventions.md)
- [CI Standard](docs/04_ci_standard.md)

Repository-local guidance may add stricter requirements, but it must not
silently contradict organization policy. An intentional exception must state
what is different, why it is necessary, and who owns removing or reviewing the
exception.

Before submitting a change, run the repository's local validation entry point
when one exists and ensure the repository CI passes.
